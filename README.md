# 大掌柜 · 在线演示

> **面向中小批发商的进销存系统**——离线优先、数据自主、买断制。
>
> **▶ [点击进入演示](https://zento21.github.io/dazhanggui_demo/)** —— 单文件交互 Demo，打开即用，**免登录直达主界面**，不需要数据库、不需要安装、不需要联网。

## 演示里可以做什么

- 录单（拼音/别名快录）→ 报单校对 → 发货 → 收款核销 → 看账指标
- 采购入库、月结锁账、客户商城管理
- 全部写操作即时生效（演示态内存），关闭浏览器即复原

演示数据为虚构商家：约 130 张订单、23 家客户（含门店坐标）、20 个库存批次、74 张发货单、74 笔应收、39 笔收款。店名、电话、坐标、供应商均非真实经营信息。

完整系统含桌面软件（Tauri，数据存商家本机）与局域网多端网页版。

## 建议的体验路径

1. **首页**——今天的待办与关键数字
2. **订单管理**——试筛选行：状态下拉、时间预设（今日 / 近 7 天 / 本月…）、「筛选」浮层里的区县与来源
3. **进销存管理**——库存预警、批次效期、商品与库位档案
4. **客户关系**——客户列表与门店分布图
5. **经营分析**——毛利、周转、账龄

## 键盘快捷键

按 `?` 查看全部。常用的：`Ctrl+K` 全局搜索、`G` 然后 `O/I/C/M` 跳页面、`J/K` 列表上下移、`Enter` 打开选中行、`N` 开录单、`/` 聚焦搜索、`Esc` 关闭弹窗。

## 这是什么，不是什么

这是**界面与交互演示**：所有操作都在浏览器内用内置的模拟数据完成，不写入任何真实数据库，刷新页面即回到初始状态。

它是产品的一个快照，不是开发版。要看源码、跑开发环境、看架构文档，请访问主仓库。

## 技术

单个 HTML 文件，内联前端 bundle、演示数据快照与 mock API（约 1.8 MB）。前端 Vue 3 + TypeScript，无组件库，自研两列式 UI。
